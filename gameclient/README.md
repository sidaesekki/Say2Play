# Say2Play — 텍스트 탑뷰 게임

`index.html`을 브라우저에서 열면 바로 실행됩니다. 빌드나 패키지 설치가 필요 없습니다. 웹 폰트를 불러오지 못해도 시스템 폰트로 플레이할 수 있습니다.

로컬 서버를 이용하려면 저장소 루트에서 `python3 -m http.server 8000`을 실행하고 http://localhost:8000/gameclient/ 로 접속하세요.

플레이어는 맵 아래쪽에서 북쪽을 바라보고, 적은 위쪽에서 남쪽을 바라보며 시작합니다. 각자의 입력창에 명령을 입력하면 독립적으로 실행됩니다.

## 명령

- 이동: `위로 이동`, `아래로 이동`, `왼쪽으로 이동`, `오른쪽으로 이동` (화면 기준, 바라보는 방향은 유지)
- 회전: `오른쪽으로 돌기`, `왼쪽으로 돌기` (90도)
- 공격: `공격` — 바라보는 방향으로 검을 휘두릅니다.
- 방어: `방어` — 1.1초 동안 전방 방어막을 펼칩니다.
- 구르기: `구르기` — 바라보는 방향으로 1칸 이동합니다.
- 반복: `공격 2번`, `오른쪽으로 돌기 2회` (1~20). 이동과 구르기는 한 명령에서 1칸만 가능합니다.
- 연결: 쉼표 또는 줄바꿈으로 분리합니다. 예: `위로 이동, 오른쪽으로 돌기, 공격, 방어, 구르기`

Enter로 실행하고 Shift+Enter로 줄바꿈합니다. 두 캐릭터의 명령은 각자 순서대로 실행됩니다. 한 번에 60개, 캐릭터별로 실행 중인 동작을 포함해 100개까지 예약할 수 있습니다. 잘못된 명령이 섞여 있으면 해당 입력 전체를 실행하지 않습니다. 초기화 버튼은 두 캐릭터의 실행 중인 동작과 대기열을 지우고 시작 위치로 되돌립니다.

다른 캐릭터가 있는 칸이나 점유 예정인 칸으로는 이동할 수 없습니다. 맵 경계도 넘어갈 수 없습니다. 공격과 방어는 현재 시각적 동작이며 체력이나 피해 계산은 없습니다.

## 구성

- `index.html`: 화면과 캐릭터별 명령 입력 UI
- `style.css`: 반응형 레이아웃
- `game.js`: 명령 해석, 캐릭터별 순차 실행, Canvas 렌더링
